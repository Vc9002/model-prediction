<objective>
Make every piece of code that computes model-edge win/loss, P&L or ROI from the auto-buyer ledger (`auto_buyer_ledger.jsonl`, live and paper) leave out hand-placed `MANUAL-*` rows, and use one shared rule to do it. Today the only exclusion is the daily-spend sum in `_today_auto_buyer_totals`. The Python summary, the dynamic model quarantine and the dashboard's client-side KPIs all still count MANUAL rows.

Purpose: `_manual_position_rows` imports hand-placed exchange positions so that settlement, the dashboard and the buyer's dedup can see them. Its docstring says they are "Tagged `manual` so model audits can exclude them". They carry no model edge (edge missing, line null, units meaningless), so counting them as buyer wins or losses corrupts the record that Vincent judges the buyer and models by. This is item 2 of Phase 1 in the ledger-improvement plan.

Output: one shared Python predicate, a JS version of it, three fixed consumers, producer-shaped regression tests, and an audit verdict for every buyer-ledger reader, recorded in the SUMMARY.
</objective>
