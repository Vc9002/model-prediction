# Quick 261115-1m7: NCAAB v7 shadow challenger and feature tests

**Result: v7 (tier-prior ridge + v6 tail + carryover 0.5 + non-D1 rule) cuts D1 holdout margin RMSE from 14.20 to 13.28 and ties v6 on moneyline Brier. It is not promoted, and the market-relative evidence is thin.**

## Item 9 (high priority): v6 retune train/serve parity

**No parity break in the v6 code or parameters.** Ablation kwargs vs the artifact factory: 0 parameter differences; identical inputs give identical margins (max abs diff 0.0 over 1,069 games).

**One input differs: the neutral flag.** The ablation builds `UpcomingGame` without `neutral_site`; serving passes it. 273 of 1,043 validation games are neutral (ESPN `neutralSite`); the `TRNMNT` proxy disagrees with the real flag on 266 of 6,947 games. Scored home-only, the HCA grid 7.2/70, 6.0/55, 5.0/45 had validation bias -2.50, -1.62, -0.93; with the real flag it is -1.22, -0.57, -0.06. **The retune is still selected** (5.0/45: bias -0.06, D1 RMSE 11.109, cover Brier 0.2104, also best on non-neutral games only), so the input gap exaggerated the over-prediction by 0.9 to 1.3 points but did not change the choice.

**The post-retune positive bias is early-season compression, not HCA.** Regression of actual minus v6 on v6 (D1 non-neutral): slope of actual on v6 is 1.62 (Nov-2025), 1.43 (Dec-Feb), 1.17 (Mar), 1.61 on the 2026-11 holdout, with intercepts -2.0, -1.9, -0.4, -0.9. I could not reproduce the exact +4.3 / +1.9 / +0.2 live figures (I did not have those rows); v6's daily D1 bias in my walk-forward falls from +6.5 (11-09) to +0.7 (11-13) and -1.3 (11-14) as team samples grow.

Also noted, identical in train and serve (so a v7 candidate, not a break): `EloBook.update` and `_effective_priors` apply home advantage to neutral history games.
