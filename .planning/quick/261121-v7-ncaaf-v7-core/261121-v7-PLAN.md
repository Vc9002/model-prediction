## Contract

- Windows = v5 artifact / recheck / v6.2 boundaries: train <= 2022-11-11, validation 2022-11-12..2024-11-14,
  locked holdout >= 2024-11-15 (60/20/20 complete-date split of the 9,511 FBS-involved replay games).
- Point in time: decision time for a game = min(kickoff, 08:00 America/New_York on the game's ET date). A game
  feeds ratings only if kickoff + 5 h <= decision (v6's D-RES-BUFFER). League means, home field, class offsets
  and the season prior are computed from admitted games only. (v5's replay uses bare start < kickoff: a small
  information advantage to v5, stated in the report.)
- Holdout rows are written to a separate file that only `holdout` loads; `holdout` refuses to run twice
  (holdout_read marker) and refuses to run without the pinned rule whose sha256 matches.
- ESPN closing lines never enter any v7 fit or selection; they are read only by the holdout market block.
  Every ESPN lined window 2017-2025 was read before (v6, v6.1, v6.2, recheck): market numbers are design-informed.
- Same games: v5, v7 and the consensus baseline are scored on the intersection; dropped counts reported.

## Tasks

1. `features/cfb_features_v7.py`: game spine (v6 history snapshot + pbp rows, ESPN ids), per-season class
   from FBS-FBS participation, weekly ridge ratings (offence and defence per metric: success rate, yards per
   play, explosive rate, points per drive, points, plays, turnover rate; garbage-filtered `_ng` metrics),
   prior centre = class mean + rho_k * (last season final - class mean), ridge strength lambda in game units,
   within-season recency half-life; stage-2 linear team-points model -> margin, total.
2. `scripts/cfb_v7_fit.py walk`: PIT features for every FBS-involved game for each grid point; train /
   validation rows and holdout rows to separate files. `fit`: rho on train seasons, stage-2 OLS on train,
   keyed margin pmf + SD model and total SDs on train; select the grid point on validation (pinned metric).
3. `pin`: write the selection rule, the gate and the CFBD-arm rule; record sha256; commit before `holdout`.
4. `holdout` (once): reproduce v5's published holdout row (n 1949, MAE 13.167, Brier 0.17197) first; then v7 vs v5
   vs consensus on the same games: MAE, Brier, log loss, calibration by favourite size, week band 0-4 / 5+,
   FBS-FBS / FBS-FCS; market block: corr(model - line, result - line) with date-clustered CI, orthogonalised slope,
   ATS 3+/7+ at 52.4% break-even, totals the same.
5. If PASS: artifact, serving module (fail-closed NO_CALL_* when a team has no admitted pbp), parity test from a
   truncated-history fixture, registry entry (not routed), registry pins. Otherwise report RESEARCH ONLY / FAILED.
6. Pre-registered 2027 gate doc (CLV primary, MAE vs opener + orthogonalised slope secondary, Brier tertiary).
7. CFBD preseason prior: added when `data/research/ncaaf_v7/cfbd/` lands (validation-selected; rule in the pin).
