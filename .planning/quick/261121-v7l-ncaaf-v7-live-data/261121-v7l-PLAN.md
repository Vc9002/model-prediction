# quick-261121-v7l: NCAAF v7 live data pipeline

## Goal

cfb-structural-v7 can be priced point in time inside the daily run from data under the runtime root:
play-by-play team-game rows (FBS and FCS, including FCS-vs-FCS), a schedule/result index, a season-level
FBS/FCS class map, and this season's CFBD preseason rows. Routing (which markets v7 serves) is out of scope.

## Design

Runtime layout (`RuntimePaths.ncaaf_v7_root` = `<runtime>/research/ncaaf_v7/`):

| file | content |
|---|---|
| `schedule.jsonl` | append-on-change ESPN scoreboard records (groups 80 and 81), one per event state change, `observed_at_utc` = scan time |
| `scan_ledger.json` | per ET date: last scan time, events, closed flag |
| `raw/<season>/<event>.json.gz` | ESPN summary wrapper (same format as the research crawl) |
| `crawl_manifest.jsonl` | fetch outcomes, last record per event wins |
| `team_game_pbp.jsonl` | team-game rows (research format) + `observed_at_utc` (= raw fetch time); appended per new raw file |
| `features_index.jsonl` | event id + raw sha256 processed, row count (processing is incremental) |
| `classes/<season>.json` | ESPN group-80 (FBS) team list for the season; every other team is FCS |
| `cfbd/team_season_priors.jsonl` | CFBD preseason rows, copied verbatim (whole seasons) |

Update step (`cfb_pbp_live.update`), bounded by a time budget and an instance lock, fail-soft:
1. Discovery first: scoreboards (groups 80 + 81) for every season date not yet closed, any unscanned date
   up to tomorrow, and the last two days. A date closes when every listed event is terminal (final,
   forfeit, cancelled, postponed) and the date has ended.
2. Fetch summaries for events final on the scoreboard with kickoff + 5 h <= now, not already terminal.
   "No plays" is terminal only when fetched >= 24 h after kickoff; before that it is retried.
3. Turn only the new raw files into team-game rows with the single row builder
   (`features/cfb_pbp_rows.py`, moved out of `scripts/cfb_pbp_features.py`, which becomes a shim).

Serving (`models/cfb_structural_v7.py`):
- Rows = pbp rows of seasons S-1 and S + score-only rows for final schedule games without pbp, exactly
  `scripts/cfb_v7_fit.py::load_team_games`; rows observed after the decision time are dropped.
- Classes from `classes/<season>.json` for S-1 and S; CFBD covariates from season S rows.
- Gate: every season date through the decision's ET date must have been scanned, else every game is
  NO_CALL_V7_PBP_MISSING. Per game: every schedule game of either team with kickoff + 5 h <= T (not cancelled
  or postponed, not terminally without pbp) must have a pbp row, else NO_CALL_V7_PBP_MISSING. The live
  `processed/ncaaf/games.jsonl` adds its completed games to that check.
- `price_v7_slate(data_root, decision_time, games)` fits the rating state once per slate and returns a
  pricing or a NO_CALL reason per game; `price_game` stays as is and the slate path is tested equal to it.

Daily: `step1o_ncaaf_v7_pbp` in the capture pool (joined before forecasting), gated by
`is_sport_daily_enabled(config, "NCAAF")`, 180 s budget, not in `_material_daily_errors`.

Seed (one time, `python -m model_prediction.data_sources.cfb_pbp_live seed`): copy the research pbp rows
(adding `observed_at_utc`), 2025-2026 raw files and manifest, the v6 snapshot as schedule records, the
CFBD priors, fetch the 2025 and 2026 class lists, and sweep the 2026 season's scoreboards. Refuses to
write into a non-empty target. `--dry-run` writes nothing and reports.

## Verification

- Parity: seeded runtime rows for 2025-2026 equal the fit script's `load_team_games` rows; 2026 rows
  re-derived from the copied raw files with the moved row builder equal the research rows; seeded CFBD
  covariates equal `load_cfbd_covariates()[2026]`; ESPN class lists equal `core.season_classes` on played
  teams.
- Tests (`tests/test_cfb_pbp_live.py`): incremental second run fetches nothing; FCS-vs-FCS discovered from
  group 81; PIT (a game finished after T is not in features at T; rows observed after T dropped);
  fail-closed on missing pbp and on a scan gap; daily gating and fail-soft; slate path equals `price_game`.
  Existing `tests/test_cfb_structural_v7.py` and `tests/research/test_cfb_pbp_features.py` still pass.
- Live: catch-up update, then v7 over today's NCAAF slate with decision = now: calls vs NO_CALL reasons.
