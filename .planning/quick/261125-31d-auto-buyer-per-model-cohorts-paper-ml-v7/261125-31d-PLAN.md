**Design choice: separate per-book passes inside `run_auto_buyer_cycle`, not per-row mode, and not the paper-trial pattern.** One cycle runs up to three passes, each with its own `AutoExecutionConfig`, its own ledger root and its own caps:
1. **Live cohort pass (first):** `mode="live"`, cohorts = live cohorts only, `whitelisted_models=()`, executes only when `enabled` is true. It runs first so its pre-cycle reconcile fails closed before anything else and so the live book is evaluated before any paper fill of the same cycle exists.
2. **Legacy global pass:** the existing whitelist pass, unchanged when the state has no `cohorts` key; forced to paper whenever a `cohorts` key exists (any value, even empty or malformed). This is what keeps `nba-spread-margin-v9` (live whitelist today, buyer disabled) out of live: enabling the buyer starts PAPER NBA spread buys, never live ones.
3. **Paper cohort pass:** `mode="paper"`, cohorts = paper cohorts only, records to the shared paper ledger.

Why not per-row mode: a per-row decision puts one classification bug between a paper row and the order path. With per-book passes the paper pass's config cannot carry a live cohort and cannot execute (constructor invariant), the live pass whitelists nothing but its live cohorts, and an explicit if-raise at the submission point refuses any row in a cohort-carrying config that did not match a live cohort.

Why not the coordinator's suggested alternative (paper cohorts as sibling paper trials on the `ncaab_paper_trial.py` pattern, plus the main buyer generalised to one live cohort with global mode = live): with global mode live, every model on the state whitelist trades real money, so the live scope is "whitelist + live cohort" and the NBA spread v9 entry would have to be deleted (taking it off paper too, against the operator's "nothing comes off production" standing rule). The trial pattern also selects on saved edge only (execution edge only sanity-checked), computes caps from its scratch root rather than the shared paper ledger, defaults to a $2.50 per-game cap, is spread-only, and lives in `ncaab_paper_trial.py`, which carries another session's uncommitted hunks. The chosen design makes "only operator-set live cohorts are live, everything else paper" literally true, reuses the main buyer's full gate set for every cohort, and touches one source file.

**What happens to the existing NCAAB spread v7 5-8% paper trial** (`auto_buyer_ncaab_spread_paper_trial.json`, `enabled: false` since 2026-11-25 03:24Z): it is superseded by the live 5-12% cohort and stays disabled. Its code (`ncaab_paper_trial.py`, `_is_paper_ncaab_spread_v6_trial`) is left untouched and inert. It must not be re-enabled while the live cohort runs: it dedups only against the paper ledger and would paper-buy the same games the live cohort buys. The NBA ML v6 paper trial (`nba-moneyline-v9`, enabled) is untouched.
