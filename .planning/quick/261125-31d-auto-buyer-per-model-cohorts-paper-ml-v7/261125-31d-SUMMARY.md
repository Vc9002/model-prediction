3. **[Rule 2] Per-game cap shared across markets.** The operator asked that spread and total live buys on one game count together. Before this change the buyer capped per order, and `held_events` and `event_markets` differ per market, so two cohorts on one game could reach $50. In a cohort-carrying config, `_build_bought_index` now also returns `game_exposure`: for each game (event id, else the away/home/date matchup), each pick's `cost_usd` plus resting fallback shares times the entry price, taken from the book's own ledger. Sizing trims the target to the room left on the game, rejects a row as `rejected_budget` when less than $0.50 of room remains, and runs a belt check after rounding. Intra-cycle buys are added at requested cost. Legacy configs are unchanged. Tests: `test_live_per_game_cap_is_shared_across_spread_and_total` and `test_live_per_game_cap_counts_ledger_exposure`.
4. **Daily spend cap $500.** This is a Task 4 state value only (see the instructions below). No code defaults changed.

5. **[Rule 1] Quote provenance for NBA rows (35df1fe2).** The real-row check showed all 3 open NBA spread v9 rows in the window failing because they carry `market_quote_provenance` `decision_time_executable_quote`, the forecast's own timestamped Polymarket quote (`cli/forecast.py`). `_row_in_cohort` now accepts it under the same evidence as `archived_two_sided_bbo`: a true timestamp flag, observed-at, snapshot hash and archive path. `decision_time_sportsbook_quote` is still refused.
