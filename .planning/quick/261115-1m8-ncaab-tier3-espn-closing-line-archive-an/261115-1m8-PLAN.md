# Tier 3: market anchor

Feasibility (this session): ESPN core odds endpoint
sports.core.api.espn.com/v2/sports/basketball/leagues/mens-college-basketball/events/{id}/competitions/{id}/odds
returned a non-live spread for 67/70 sampled events 2022-23..2026-27, each item with open/close/current blocks.
Providers vary by era (2022-23/2023-24: 10-15 books; 2024-25: ESPN BET only + a "Live" item to exclude; 2025-26+: DraftKings only).
Local history file covers only 2025-26 and 2026-27; earlier event ids come from the ESPN scoreboard (groups=50, limit=400, one call per date).
About 26,000 events, ~3.5 h at 0.4 s/request. No technical blocker.

## Build (template: scripts/cfb_v6_espn_lines.py, cfb_v6_market_check.py, cfb_v6_residual.py)
1. scripts/ncaab_espn_lines.py: resumable append-only fetch, single worker, read-only GET, generic User-Agent (no project/user details), polite pacing, progress file. PINNED line rule hashed and stamped on every record BEFORE any outcome join: median of non-live providers' close values, spread and total separately, home spread negative when home favoured, drop |spread|>70 and totals outside [15,120], reuse the NCAAF plausibility drops (2022-23 close blocks sometimes carry prices in the line field). Also store open and close both (for line movement). The fetch script NEVER joins outcomes. Add `verify` (re-fetch 25 random stored events) and `analyze` (coverage audit). Run the fetch in the background for seasons 2022-23..2025-26 plus 2026-27 to date; data goes under the runtime/outputs ignored trees, not tracked git paths (CLAUDE.md: data/ trees are untracked).
2. scripts/ncaab_residual.py: bounded market-anchored residual test. Anchor = closing line. Features: v6 model-minus-line (rebuild PIT v6 projections walk-forward; seasons before 2025-26 need history rebuilt from the scoreboard games - if scores are not available for earlier seasons, fetch them in the same resumable fashion from ESPN scoreboard results), plus candidates tested individually and jointly: opening-to-closing line movement, tempo/pace, rest, neutral site, early-season sample size, non-D1 flag. Ridge of (actual margin minus line) / (actual total minus line); walk-forward by date (fit 2022-23..2023-24, validate 2024-25, LOCKED holdout 2025-26, final live check 2026-27); date-clustered bootstrap CIs; shrink residual; bet only if |pred residual| >= 1 point. Accept only if validation slope CI lower bound > 0 AND out-of-sample MSE delta CI > 0 (the NCAAF rule); otherwise report NO PICK. Evaluate cover rate and ROI at an executable price assumption (Polymarket ask often 53-54%, not 52.4%); exclude pushes.
3. Power statement in the report: ~43,000 bets to confirm a true 53% cover vs 52.4% break-even; 2,300 for 55%; the archive supports detecting ~54%+ only.
