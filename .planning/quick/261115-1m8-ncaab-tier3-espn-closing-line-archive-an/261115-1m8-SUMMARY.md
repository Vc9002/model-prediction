# Phase quick-261115-1m8 Plan 1: NCAAB Tier 3 market anchor Summary

ESPN closing-line archive for 25,880 completed NCAAB games (2022-23 through 2026-27 to date) plus a pinned,
walk-forward market-residual test: nothing we can compute before tip-off explains (actual - closing line), so the
verdict is **NO PICK** on spreads and totals.

## What was built

- `scripts/ncaab_espn_lines.py`: resumable, append-only, single-worker, read-only GET (generic `Mozilla/5.0`
  User-Agent, no project or user detail in any request), paced at 0.4 s. Commands `scoreboard`, `fetch`, `verify`,
  `analyze`. Pinned line rule `ncaab-espn-lines-rule-1` (sha256 `e0f6811d...`) is stamped on every stored odds
  record; the fetch script never joins outcomes. Data lives in `data/research/ncaab_market/` (gitignored).
- `scripts/ncaab_residual.py`: rebuilds point-in-time v6 projections by calling the served
  `ncaab_spread_v6_model()` / `ncaab_total_v6_model()` read-only on scoreboard-derived history, builds PIT candidate
  features, and applies pinned rule `ncaab-residual-rule-1` (sha256 `58c37344...`, committed in 45c2938e before any
  outcome was joined; the later script edit in efedf0ba only added descriptive output, the rule hash is unchanged).
- `tests/research/test_ncaab_market_scripts.py` (9 tests, `pytest tests/research/test_ncaab_market_scripts.py -o
  addopts='' -q`): orientation never trusts the raw `spread` sign, live items excluded, price-like values dropped,
  rule-hash refusal, side record with pushes and zero bets, ridge/bootstrap on synthetic signal and noise, and the
  accepted / NO PICK / zero-bet paths of `run_market` and `render_md`.

## Result (full detail in outputs/ncaab/ncaab_residual.md)

Windows by ESPN season year: fit 2022-23 and 2023-24 (11,605 spread / 11,660 total rows), validation 2024-25 (5,763 /
5,762), locked holdout 2025-26, live check 2026-27. Family K = 9 per market (movement models qualified on opening-line
coverage); acceptance uses date-clustered bootstrap bounds at alpha 0.025 / K, with the plain 95% bounds shown too.

- **Spread: NO PICK.** All nine models fail both criteria. Raw v6-minus-line slope on the validation window -0.047
  (95% CI -0.147 to +0.056). Following the raw v6 gap (|gap| >= 1): 2,082-2,108 on validation, 49.7% cover,
  ROI -5.2% at the 52.4% break-even and -7.1% at a 53.5% executable ask (CI excludes break-even on the wrong side).
- **Total: NO PICK.** All nine fail. Raw slope -0.011 (95% CI -0.122 to +0.102). Raw v6 side: 2,350-2,379, 49.7%
  cover, ROI -5.2% and -7.1% at the same prices.
- The only validation side record that looks positive (spread m_sample, 127-112, 53.1%, CI 48.1% to 58.1%) fails the
  MSE criterion and is one of 18 models; it is noise at this sample size, not a finding.
- The locked holdout (2025-26) and live check (2026-27) were not scored: the rule says they are scored only for an
  accepted model, so both remain unspent.
- Plain 95% bounds (the plan's literal rule) were checked per model in the JSON: no model has both lower bounds above
  zero on either market, so the Bonferroni deviation changed nothing.
- Power: confirming a true 53% cover rate against the 52.4% break-even needs about 42,900 bets (80% power, one-sided
  5%); 54% needs about 6,000; 55% about 2,300; 56% about 1,200. The validation window supports about 4,200 raw-gap
  bets on spreads and 4,700 on totals (fit window about 8,300 and 9,800), so the archive can only detect an edge of about 54% or more. A true 52.5% to 53.5% edge would pass
  unnoticed. A "no skill" verdict therefore means "no edge of roughly 54% cover (about 1.6 points over break-even) or better",
  not "no edge".

## Caveats (also stated in the outputs)

0. Fit-window leverage. The spread `m0_v6` fit coefficient is 0.61 standardised on about 11,600 rows, yet following the
   same gap in the fit window covers only 49.9%. The signal sits in small cohorts: in `m_nond1` the v6 coefficient
   drops to 0.21 with `x_nond1` at 1.05, in `m_sample` to 0.11 with `x_early` at 0.82. Outcome-free counts of lined
   rows with a non-D1 side: 71 (2022-23), 94 (2023-24), 0 afterwards; lined events with no sportsbook among their
   non-live providers: 14 and 63 in the fit seasons, 0 afterwards. The 2022-24 median also includes
   projection providers (the NCAAF template had a book-only robustness line; this run did not). This does not
   change the verdict (the validation raw slope is negative with a CI spanning zero, independent of the fit) but it
   biases the MSE criterion toward NO PICK and may distort the candidate-feature coefficients. A book-only or
   D1-only re-fit is an unrun, post-hoc follow-up, not part of this verdict.
0b. Half-point lines. All 5,763 lined 2024-25 events (ESPN BET) and 5,677 of 5,744 in 2025-26 (DraftKings) carry
   half-point spreads, against 59% in 2022-23 and 62% in 2023-24; the validation window therefore has 0 pushes by
   construction (fit has 114 spread and 60 total pushes). That is a property of the archive (the books, or ESPN's
   rounding of their lines), not a join problem, and it also means validation cover rates are not comparable to
   whole-number-line eras.

1. The line is a CLOSING benchmark with no per-quote observed_at, not a decision-time quote.
2. Opening-to-closing movement is closing-based and cannot serve a live decision; it is a family member for
   reporting but can never be an accepted pick model (criterion c). Its "open" block in the 2022-24 multi-book era
   is the provider's own and was not independently verified as a true opening quote.
3. The served v6 parameters were selected on 2025-26 data, so the locked holdout is not out-of-sample for v6.
4. The benchmark changes across windows (multi-book median, then ESPN BET, then DraftKings), so a relationship can
   differ by window because the line source changed.
5. The v6 conference map is today's, applied to 2022-25 games; AP ranks and box stats come from the scoreboard feed
   as served at fetch time (an as-of rank for a past game is unverified).
6. Executable ask prices differ from 52.4%; ROI is shown at 52.4% and 53.5%. No American odds are used anywhere.

## Deviations from Plan

**1. [Rule 1 - Bug] Totals plausibility band**
- **Found during:** fetch smoke test of the pinned rule (first test run).
- **Issue:** the plan said to reuse the NCAAF drop of totals outside [15, 120]; basketball totals are 120-190, so
  that band would have dropped every total.
- **Fix:** band [90, 250]; the first fetch (250 events in) was stopped and its file deleted before the rule hash was
  first stamped on a kept record. The restart is the real first fetch (`first_fetch_started_at_utc` in the progress
  file). The spread plausibility drop (|x| > 70) is unchanged.
- **Commit:** 45c2938e

**2. [Rule 3 - Blocking] Scoreboard re-fetch for tempo/rank inputs**
- The first scoreboard pass (150 dates) stored too few box-stat fields for the v6 models' scoreboard-stats reader;
  it was stopped, deleted and re-run with all eight stat fields and AP rank (about 6 minutes lost).

**3. [Scope addition] 2021-22 scoreboard fetched (burn-in)**
- Rating history for the first 2022-23 games needs the prior season. Scoreboard only, no odds were fetched for it.

**4. [Rule 2 - Missing critical functionality] Multiplicity control**
- The plan's rule is the NCAAF plain-95% rule. With nine models per market that overstates significance, so
  acceptance uses a Bonferroni bound (alpha 0.025 / K per tail); the plain 95% bounds are reported alongside. This
  is stricter than the plan; nothing was close to passing either way (every lower bound is below zero at 95% too).

**5. Plan wording resolved by pinning**
- "Ridge ... shrink residual": alpha 1000 on standardised features and a 0.5 shrink on the prediction, bet threshold
  1.0 point; all pinned in the rule block before the first outcome join. Tests live under `tests/research/` (the
  default pytest skips that tree) rather than `tests/`.

**6. Shared-tree notes**
